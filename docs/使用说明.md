# 在线字幕翻译工具 — 使用说明

本说明分两部分：
- **A. 本地使用**：在自己电脑上跑起来（开发 / 自用）。
- **B. 在线部署使用**：部署到公网服务器（宝塔 Node 项目），多人/远程访问。

两种场景**界面操作完全一致**（见「C. 操作流程」），区别只在「怎么把它跑起来」。

---

## A. 本地使用

### A.1 环境要求

- Node.js ≥ 18（推荐 20 或更高；开发用 24 亦可）
- npm（随 Node 安装）
- 一个可用的 OpenAI 兼容 API（Base URL + Key + 模型名），如 OpenAI / DeepSeek / Kimi / 智谱 / 本地 Ollama

### A.2 启动开发模式

```bash
# 1) 安装依赖（首次）
npm install

# 2) 启动开发服务器
npm run dev
```

浏览器打开 **http://localhost:3000** 即可使用。

### A.3 本地以「生产模式」运行（更接近线上）

```bash
npm run build      # 构建
npm start          # 启动生产服务（默认 3000 端口）
```

如需换端口：

```bash
# macOS / Linux
PORT=4000 npm start
# Windows PowerShell
$env:PORT=4000; npm start
```

### A.4 运行测试（可选，验证核心逻辑）

```bash
npm test           # 跑一遍单测：解析往返一致、行对齐、编码、命名等
```

### A.5 本地使用注意

- 本地直接用 `localhost`，**无需 HTTPS**，API Key 只留在你本机浏览器，安全风险低。
- 若用本地 Ollama：Base URL 填 `http://localhost:11434/v1`，模型名填你 `ollama pull` 的模型（如 `qwen2.5`）。

## B. 在线部署使用（宝塔「Node 项目」）

> 目标形态：Nginx 反代 + Let's Encrypt HTTPS + 网站密码（Basic Auth）把整站挡在登录后。

### B.1 准备

- 一台装好**宝塔面板**的服务器，已安装 **Node 版本管理器** 与 **PM2**（宝塔软件商店里有）。
- 一个解析到服务器的**域名**（用于上 HTTPS）。
- 把本项目代码上传到服务器某目录，如 `/www/wwwroot/subtitle-translator`。

### B.2 构建

在项目目录执行（可用宝塔「终端」或「Node 项目」的命令钩子）：

```bash
npm install
npm run build
```

### B.3 新建「Node 项目」

1. 宝塔左侧「网站」→「Node 项目」→「添加 Node 项目」。
2. **项目目录**：指向 `/www/wwwroot/subtitle-translator`。
3. **启动选项 / 启动命令**：`npm start`（Next.js 默认监听 **3000** 端口）。
4. **运行方式**：PM2（守护进程，崩溃自动重启）。
5. 保存并启动，确认进程在跑、3000 端口已监听。

> 提示：也可使用 standalone 产物（`.next/standalone`）来跑，本项目已开启 `output: "standalone"`。简单起见，直接 `npm start` 即可。

### B.4 反向代理 + HTTPS

1. 「网站」→「添加站点」，绑定你的域名（可不建数据库、纯静态占位）。
2. 进站点设置 →「反向代理」→ 添加：
   - 目标 URL：`http://127.0.0.1:3000`
   - 发送域名：`$host`
3. 站点设置 →「SSL」→ 选「Let's Encrypt」一键签发，开启「强制 HTTPS」。

### B.5 整站加密码（强烈建议）

站点设置 →「网站密码」/「访问限制」→ 设置 **HTTP Basic Auth** 用户名密码。
这样所有人访问前都要先登录，配合 HTTPS 才能安全地在公网用带 Key 的工具。

> ⚠️ 公网 + 带 Key + 没有 HTTPS = 不可接受。务必先 HTTPS 再用。

### B.6 升级 / 重启

代码更新后：

```bash
git pull            # 或重新上传代码
npm install         # 依赖有变动时
npm run build
```

然后在宝塔「Node 项目」里点「重启」。

### B.7 部署后访问

浏览器打开 `https://你的域名` → 输入网站密码 → 进入工具界面。

## C. 界面布局总览

打开后界面分三块：

- **顶部工具栏**（始终可见）：左侧「字幕翻译」标题 + 翻译状态徽标（未翻译 / 翻译中 x% / 已完成翻译）；右侧 —— **打开文件**、**打开文件夹**（批量）、**导出仅译文**、**导出双语**、**主题切换**（🖥跟随系统 / ☀浅色 / 🌙深色，默认跟随系统）、**⚙ 设置**。
- **控制条**（上传文件后出现，吸附在工具栏下）：**翻译服务**切换、**原始语言**、**目标语言**、**开始翻译/取消**按钮。
- **质量工具条**（上传文件后出现）：**术语表**、**译文体检**、**源字幕清理**三个按钮，点开即展开对应面板。
- **批量队列面板**（一次载入多个文件时出现）：文件列表、进度、开始/停止、打包下载 ZIP。
- **主体**：上传前是整屏拖拽区；上传后是**完整字幕表格**（序号 / 开始时间 / 结束时间 / 原文 / 译文），所有行都显示，**译文一栏可直接点击修改**，翻译过程中实时回填；文件名下方实时显示**导出后的文件名预览**。

所有细项配置都收在 **⚙ 设置**弹窗里，分四个标签页：翻译服务、翻译参数、高级·提示词、双语与导出。
**设置弹窗里的改动是「草稿」，点底部「保存」才生效；点「关闭」则放弃本次改动。**（控制条上的翻译服务/原始语言/目标语言属于快捷切换，即时生效，不走草稿。）

## D. 操作流程（本地与在线通用）

### 第 1 步 · 配置翻译服务（首次必做）
点右上角 **⚙ 设置 →「翻译服务」**标签：
- 点 **「+ 添加服务」**，再点服务预设（**OpenAI / DeepSeek / Moonshot / 智谱 / Ollama**）会**一键带入名称、Base URL、模型名**，按需改 API Key 即可；也可全部手填。
- 点 **「测试连接」** 校验是否可用（绿色为成功）。
- 可添加**多个服务**，用单选按钮选「使用此服务」。**改完点底部「保存」**。之后在控制条的「翻译服务」下拉里可随时切换。

> 密钥只存本地浏览器，经转发路由穿透，不进源码、不进前端包。

### 第 2 步 · 打开字幕
- 上传前的整屏区域里**拖拽或点选** `.srt` / `.ass` / `.ssa` / `.vtt` / `.lrc`；或随时用工具栏 **「打开文件」**。
- 单文件 ≤ 20 MB。自动探测编码。VTT / LRC 解析后统一按 SRT 导出。
- **一次拖入多个文件、或用「打开文件夹」选择整个目录**：自动进入**批量队列**（见第 8 步）。
- **源字幕清理**：载入时会自动识别压制组问候语、字幕站水印、`**` 这类纯符号占位条、以及用半角 `?` 冒充 ♪ 的歌词行。被剔除的条目在表格里**标灰**、不翻译也不导出，可在「源字幕清理」面板里逐项关闭或单条恢复。
- **源语言自动判定**：按正文内容判断语种并回填到控制条（内封字幕的语言标签常常不可信），因此双语文件名默认就是 `AI中英双语` 而不是 `AI中文双语`。
- **ASS 说明**：会无损保留原有样式/特效，仅翻译对白（Dialogue）；注释、绘图、卡拉OK 行原样保留不翻译。双语导出为「译文 + 原文」上下两行堆叠。
- **ASS 样式**（设置 → 双语/样式）：默认**忠实保留**源字幕的字体/字号/颜色，只翻译文字（不会弄崩已排版好的字幕）。想统一外观时勾选「强制统一 ASS 样式」，即按「译文大、原文小」覆盖——字号按视频画面高度比例设定，手机/电脑都不会过大或过小；可选档位 小/中/大、自定义百分比与字体。
- **已双语提示**：若上传的字幕本身已是「中文+外文」双语，顶部会提示——再翻译会覆盖现有译文。若只想换样式，直接导出即可，不必再翻译。
- **若表格里是乱码**：上传区下方会出现编码下拉框，手动选 `gbk` / `big5` / `shift_jis` / `utf-16le` 等重新解析。

### 第 3 步 · 选语言、调参数
- 控制条里选 **原始语言**（可「自动检测」）和 **目标语言**。
- 需要时进 **⚙ 设置 →「翻译参数」**：
  - **请求最大段落数**（默认 **20**，即每次请求发给模型的条数）与**每批字符上限**（默认 1600，两者取先到者；遇到成段独白时按字符切分比固定条数稳）
  - **温度 temperature**（默认 **0**）
  - 并发请求数（默认 6）、最大重试（默认 3）、上下文参考条数（前文默认 3 / 后文默认 2，提升连贯性）
  - **思考模式**（默认 **中**）：关闭思考会让推理型模型把一句话在相邻两条字幕间错误重新分配，这类错误观众能直接看出来；追求速度/成本可调成「关闭」，再用「译文体检」挑出可疑条目重译。
  - **max tokens**（默认 16384）：思考型模型的**思考 token 也占这个额度**，给少了会返回空内容、整批静默失败。开启思考时会自动按不低于 16384 发送。
  - 自定义风格指令（追加，可选）
- 进阶可在 **「高级 · 提示词」**标签里改系统提示词模板（支持 `{{to}}`/`{{from}}` 占位符；引擎会自动追加行对齐协议，改风格不会破坏对齐）。可「恢复默认」，也可查看「沉浸式翻译预设」作参考。

### 第 3.5 步 · 生成术语表（强烈建议，翻译前做）
点质量工具条的 **「术语表」→「生成术语表」**：
- 先扫全片抽出人名/地名/昵称等专名候选（带样例台词），再调**一次**模型生成统一译名。
- 结果可**逐条手工编辑或删除**，也能手动添加。
- 翻译时术语表会按批筛选后写进提示词强制遵守。

> 为什么需要它：每批字幕是**独立的一次请求**，模型无从得知上一批把 `Robert` 译成了什么，
> 于是同一个人名常常一会儿「罗伯特」、一会儿留英文原样。术语表是跨批次统一译名的唯一手段。

### 第 4 步 · 翻译
- 点控制条 **「开始翻译」**，状态徽标显示「翻译中 x%」，表格译文列实时回填。
- 可随时 **「取消」**；已翻译的行保留。
- 中断/失败后按钮变为 **「继续翻译（剩 N）」**——只补译未完成的行（断点续传）。
- 个别多次重试仍失败的行，译文框会标红显示「未翻译」，可**手动填写**或再点「继续翻译」；表格上方会显示最后一次失败原因（如「思考 token 耗尽了 max_tokens 额度」）。
- **刷新不再白干**：翻译内容会自动存进浏览器 IndexedDB，误刷新/关页后再进站顶部会提示「继续上次的翻译」。

### 第 5 步 · 校对与体检
- 点质量工具条的 **「译文体检」→「开始体检」**：机械校验「译文与原文完全相同」「目标是中文却一个汉字都没有」「译文/原文长度比异常」三类问题，命中条目在表格里**标黄**，可一键「重译这 N 条」。
- 直接在表格 **译文列点击编辑**，失焦即保存。导出时用的就是你改后的内容。

### 第 6 步 · 双语布局与导出设置
进 **⚙ 设置 →「双语与导出」**：
- **双语布局**（选项旁有 **?** 悬停说明）：
  - **单轨**（默认）：译文与原文写在同一条字幕的两行里。
  - **双轨**：译文与原文拆成两条字幕、共用同一时间轴。⚠️ 同一时间轴上的两条字幕，Emby / Plex / Jellyfin 等播放器的堆叠渲染并不一致，可能**只显示其中一条**，因此不再作为默认。
  - **仅译文**。
- **语言顺序**：译文在前 / 原文在前。
- **合并多行为单行**（推荐开启，默认开）：字幕原文常因排版被拆成多行，双语叠加后行数会翻倍（如原文 3 行→双语 6 行）影响观看；开启后每种语言压成一行，双语共 2 行，由播放器按宽度自动折行。
- **「仅译文」/「双语」附加文字**：可自定义并保留预设（如 `AI中文` / `AI机翻中文`；`AI中英双语` / `AI机翻中英双语`）。点「自动」恢复按语言自动推断。
- **导出语言码**：默认「自动」（按目标语言推断，简体中文→`chs`），可覆盖。
- **SRT 配色方案**：默认「不分色」；另有暖金/青柠/天蓝/樱粉/纯白等**以译文（中文）为主色调**的方案（需播放器支持 `<font color>` 才生效）。改完记得点「保存」。

### 第 7 步 · 导出下载
直接点工具栏的两个按钮，文件名自动生成：
- **导出仅译文** → `原文件名.AI中文.chs.srt`
- **导出双语** → `原文件名.AI中英双语.chs.srt`（源语言已知时；自动检测时为 `AI中文双语`）

### 第 8 步 · 批量处理整个媒体库（可选）
一次拖入多个字幕文件、或用工具栏 **「打开文件夹」** 选中整个目录后，会出现**批量队列面板**：
- 选项：**每部先生成术语表**（推荐，每部片子人名不同）、**导出仅译文**、**导出双语**。
- 点 **「开始批量翻译」**：逐个文件解析 → 清理 → 术语表 → 翻译，当前处理的文件会显示在下方表格里，可随时「停止批量」，之后点「继续批量翻译」接着跑。
- 全部完成后点 **「打包下载 ZIP」**：ZIP 内**保留原目录结构**，解压回媒体库目录即可，省掉逐个改名归位。
- 单个文件也能在列表里单独下载；失败的文件会标出原因，可移除或重跑。

## E. 把字幕放进媒体服务器（Plex / Jellyfin / Emby）

1. 导出的文件名如 `电影名.2024.AI中文.chs.srt`，**基础名要和视频文件同名**（导出时已自动去掉原有语言尾标）。
2. 把字幕文件放到**与视频同一目录**。
3. 让媒体服务器刷新/扫描该影片，外挂字幕轨即会按语言码出现。

> 双语字幕没有标准语言码：用目标语言码（如 `chs`）最稳；自造的 `zh-en` 多数媒体服务器识别不了。

## F. 常见问题（FAQ）

**Q：翻译报「模型 API 返回 401/403」？**
A：API Key 或 Base URL 不对。先用「测试连接」排查；注意 Base URL 通常要带 `/v1`。

**Q：一直 429？**
A：触发了供应商限流。调低「并发请求数」、增大「请求最大段落数」、或换额度更高的账号；引擎已对 429 做指数退避重试。

**Q：译文条数和原文对不上 / 时间轴错位？**
A：本工具用「带 ID 结构化输出 + 条数校验 + 缺失重试」防这个。若仍有少量「未翻译」，点「继续翻译」重试；个别难缠的可减小「请求最大段落数」再试。

**Q：表格里是乱码？**
A：在上传区下方手动选正确编码（GBK/Big5/Shift-JIS/UTF-16）后重新解析。

**Q：翻译太慢，怎么提速？**
A：进 ⚙ 设置 →「翻译参数」调高 **并发请求数**（默认 6），并适当增大 **请求最大段落数**；受模型供应商限流约束，过高可能触发 429。
另外「思考模式」默认为「中」，关掉能快数倍、便宜数倍，但译文质量下降明显——折中做法是先用「关闭」跑完，再用「译文体检」把可疑条目挑出来重译。

**Q：想浅色/深色主题？**
A：工具栏右侧三态切换：🖥 跟随系统（默认）/ ☀ 浅色 / 🌙 深色，选择会被记住。

**Q：标签（斜体等）丢了或位置乱了？**
A：整行 `<i>…</i>` 这类会被正确保留；复杂的行内多段标签在译文长度变化大时可能位置近似——v1 已尽量保护，完整精确样式留待 ASS 阶段。

**Q：刷新页面后配置和译文还在吗？**
A：API 配置、翻译参数、样式/导出偏好存在浏览器 localStorage；**字幕与已完成的译文**会自动存进 IndexedDB，刷新或关掉页面后再进站，顶部会提示「继续上次的翻译」（只保留最近一份任务，可点「丢弃」清掉）。

**Q：同一个人名一会儿中文一会儿英文？**
A：先用「术语表」生成统一译名再翻译（见第 3.5 步）。已经翻完也可以：生成术语表后，用「译文体检」挑出可疑条目重译。

**Q：模型返回空内容 / 某些批次一直失败？**
A：多半是思考型模型的**思考 token 把 max_tokens 吃光了**。调高 max tokens（开思考时不低于 16384）、调低思考强度，或减小「请求最大段落数」「每批字符上限」。

**Q：换台电脑/换浏览器，Key 还在吗？**
A：不在。Key 只存在你当时输入它的那个浏览器里。
