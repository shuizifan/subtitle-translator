# 字幕翻译模型预设来源

核对日期：2026-11-09。代码：`src/core/translator/providerPresets.ts`。

本清单选取支持文本 Chat Completions 的现行模型，不等于供应商完整目录。模型 ID、接口和参数来自下列官方资料；“推荐”是依据速度、成本与本地资源的工程判断，并非所有模型的字幕质量实测结论。

## 顺序与默认

列表按官方代际从新到旧人工排列；同代版本优先展示高速版，同代不同参数量不表示发布时间有先后。所核对页面未提供可确认的精确 API 发布日期，因此 `releasedAt` 留作可选字段，不拿知识截止时间、版本编号或模型库更新时间冒充发布日期。默认值独立于列表顺序。

| 服务 | 预设顺序（模型 ID） | 推荐默认 |
| --- | --- | --- |
| OpenAI | `gpt-6.1-terra` → `gpt-6-luna` → `gpt-5.6-luna` | GPT-6 Luna，官方定位高吞吐效率模型 |
| DeepSeek | `deepseek-flash` → `deepseek-v4-pro` | Flash，当前服务版本为 V4.1 Flash |
| Moonshot | `kimi-k3.1-pro-highspeed` → `kimi-k3.1-pro` → `kimi-k3` | K3.1 Pro 高速版 |
| 智谱 | `glm-5.3-flashx` → `glm-5.3-flash` → `glm-5.3` | Flash，兼顾成本 |
| Ollama | `qwen3.8:27b` → `qwen3.5:9b` → `qwen3.5:4b` | Qwen3.5 9B，兼顾本地资源 |

## 官方依据

### OpenAI

[模型目录](https://developers.openai.com/api/docs/models/all)、[GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra)、[GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)、[GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)。所选模型支持文本输入输出及 Chat Completions；Luna 面向高量任务。未加入目录已标记 Deprecated 的老型号。

[Chat Completions 参数](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)明确 `max_completion_tokens` 包含可见输出和思考 token；模型页明确支持 `low`。新预设使用这两个设置，温度不主动发送。

### DeepSeek

[官方接入指南](https://api-docs.deepseek.com/quick_start/pricing)列出 `deepseek-flash` 与 `deepseek-v4-pro`，并说明 Flash 别名现在对应 DeepSeek-V4.1-Flash-1017。已退役模型对应的旧别名不单独展示。使用官方示例 Base URL `https://api.deepseek.com`；没有将未核实的思考枚举加入预设。

### Moonshot / Kimi

[模型目录](https://platform.kimi.ai/docs/models)、[K3.1 Pro 接入](https://platform.kimi.ai/docs/guide/kimi-k3-1-pro-quickstart)、[K3 接入](https://platform.kimi.ai/docs/guide/kimi-k3-quickstart)。K3.1 Pro 高速版是官方提供的加速变体。K3 系列始终思考，支持 `low` / `high` / `max`，默认 `max`；因此字幕预设使用 `low`，并发送 `max_completion_tokens`。固定温度参数省略。新建服务使用官方示例 `https://api.moonshot.ai/v1`，原有用户 URL 不应被迁移覆盖；该域名已在应用白名单内。

### 智谱

[GLM-5.3](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)、[GLM-5.3 Flash / FlashX](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)。Flash 页面给出确切模型 ID，文本参数沿用 GLM-5.3；后者支持 `low` / `high` / `max` 并默认 `max`。预设改用 `low` 以减少字幕任务的推理耗时；未加入法律专项模型。FlashX 是更快的同代变体，Flash 是成本优先的推荐项。

### Ollama

[Qwen3.8](https://ollama.com/library/qwen3.8)、[Qwen3.5](https://ollama.com/library/qwen3.5)、[OpenAI 兼容接口](https://docs.ollama.com/api/openai-compatibility)。预设标签必须先安装，例如 `ollama pull qwen3.5:9b`；预设不会自动下载模型，也不保证设备内存充足。API Key 可填服务器忽略的占位值 `ollama`。

本应用由服务端代理模型请求，`localhost` 指应用服务器。Vercel 预览不能通过它访问用户电脑；本地 Ollama 需要本地运行应用或配置应用服务器可达的端点。私网访问仍遵循现有服务端显式开启规则，不因选中预设自动放行。

## 使用边界

选择模型预设时才应用对应建议参数，已有自定义模型和独立保存的模型设置应保留。未知模型仍允许手动输入。页面中的列表是核对当日的静态快照，不代表用户账户必然已开通所有型号；服务连接和翻译协议测试用于验证实际账户可用性。
